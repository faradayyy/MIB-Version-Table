## MIB Train-Version Naming Convention
```
<TrainPrefix><Gen><Suffix>_<Region>_<Brand/Variant>_<Platform>_<Version>
```

| Code | Country |
|---|---|
| AS | Asia |
| CN | China |
| EU | Europe |
| ER | Europe + Rest of World |
| JP | Japan |
| KR / XB | South Korea |
| NAR | North America Region |
| US | United States |
| RoW | Rest of the World |
| RoA | Rest of Asia |
| TW | Taiwan |
